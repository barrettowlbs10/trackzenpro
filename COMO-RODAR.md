# 🚀 TrackZen Pro — Como rodar no seu computador

## Passo 1 — Abra a pasta no VSCode
Abra o VSCode → Arquivo → Abrir Pasta → selecione a pasta "trackzenpro"

## Passo 2 — Abra o terminal
No VSCode: menu Terminal → Novo Terminal
(ou pressione Ctrl + ` )

## Passo 3 — Instale as dependências (só na primeira vez)
Digite no terminal e pressione Enter:
```
npm install
```
Aguarde terminar (pode demorar 1-2 minutos)

## Passo 4 — Rode o servidor
```
npm start
```

## Passo 5 — Abra no navegador
Acesse: http://localhost:3000
